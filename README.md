# MaKSAd – Volunteer & Event Management System

MaKSAd is a Software Engineering course project that focuses on designing and implementing a system for managing volunteers, events, and participation records.  

The system was implemented using **Java Swing** (GUI) and **MySQL**, and follows Software Engineering principles.

---

## Purpose & Scope (Software Engineering Context)

The goal of the project was to design a system that allows organizations to:

- Manage volunteers
- Create and organize events
- Track participation
- Issue certificates
- View reports

The application demonstrates practical skills in:

- Requirements definition
- System modeling
- UI/UX design
- Database design
- OOP implementation
- Testing & validation

---

## Functional Modules

- **User Management**  
  (Admin, Organizer, Volunteer roles)

- **Event Management**

- **Participation & Attendance Tracking**

- **Certificates Management**

- **Reports**
